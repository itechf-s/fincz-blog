# 📋 **Claude Code Master Course — Poora Syllabus**

Ye course 7 Modules aur 18 detailed lessons me bata hua hai. Niche har module ka topic detail diya gaya hai:

---

## 🔹 **Module 1: Foundations & Architecture**
1. **[1.1 Agentic Coding vs Vibe Coding](/courses/claude-code/module-01-foundations/01-agentic-coding-vs-vibe-coding/)**: Normal Chatbot, Copilot autocomplete aur Autonomous Agentic Loop me kya farq hai?
2. **[1.2 What is Claude Code & Architecture](/courses/claude-code/module-01-foundations/02-what-is-claude-code/)**: Terminal Tool ka architecture, permissions aur background me kaise kaam karta hai.
3. **[1.3 Installation & Setup](/courses/claude-code/module-01-foundations/03-installation-and-setup/)**: Node.js, CLI Install (`@anthropic-ai/claude-code`), Anthropic API Key aur Free credits setup.

---

## 🔹 **Module 2: Everyday CLI & Core Workflow**
1. **[2.1 Slash Commands Mastery](/courses/claude-code/module-02-core-workflow/01-slash-commands-mastery/)**: `/help`, `/init`, `/compact`, `/cost`, `/doctor`, `/review` jaise zaruri commands.
2. **[2.2 Making Code Changes & Diffs](/courses/claude-code/module-02-core-workflow/02-making-code-changes/)**: Files edit karna, Code diffs dekhna aur safe terminal execution.
3. **[2.3 Multimodal Image Context](/courses/claude-code/module-02-core-workflow/03-multimodal-image-context/)**: UI Designs, Screenshots aur Wireframes ko terminal prompt me pass karna.

---

## 🔹 **Module 3: Context Window & Memory Management**
1. **[3.1 Context Window Management](/courses/claude-code/module-03-context-and-memory/01-context-window-management/)**: Token limits samajhna, paise/cost bachana aur `/compact` ka sahi use.
2. **[3.2 CLAUDE.md — The Project Brain](/courses/claude-code/module-03-context-and-memory/02-claude-md-the-master-file/)**: Project rules, coding standards aur instructions save karna.

---

## 🔹 **Module 4: Development Workflows & Planning**
1. **[4.1 Spec-Driven Development (SDD)](/courses/claude-code/module-04-development-workflows/01-spec-driven-development/)**: Specs aur Requirements likh kar bina error ke code banwana.
2. **[4.2 Plan Mode & Ultraplan](/courses/claude-code/module-04-development-workflows/02-plan-mode-and-ultraplan/)**: Code likhne se pehle step-by-step planning aur dependency graph.
3. **[4.3 Custom Slash Commands](/courses/claude-code/module-04-development-workflows/03-custom-slash-commands/)**: Apne project ke liye `.claude/commands/` me custom shortcuts banana.

---

## 🔹 **Module 5: Skills & SubAgents Architecture**
1. **[5.1 Claude Code Skills](/courses/claude-code/module-05-skills-and-subagents/01-claude-code-skills/)**: `SKILL.md` banakar repeated tasks aur workflows ko package karna.
2. **[5.2 Built-in SubAgents](/courses/claude-code/module-05-skills-and-subagents/02-built-in-subagents/)**: Subagents ko kaam baant kar tokens aur main context bachana.
3. **[5.3 Custom SubAgents](/courses/claude-code/module-05-skills-and-subagents/03-custom-subagents/)**: Alag-alag kaam ke liye worker agents (Testing, QA, Documentation) banana.

---

## 🔹 **Module 6: Model Context Protocol (MCP) & Plugins**
1. **[6.1 Claude Code + MCP](/courses/claude-code/module-06-mcp-and-integrations/01-claude-code-with-mcp/)**: Database (PostgreSQL), GitHub aur Browser tools ko Claude Code se connect karna.
2. **[6.2 Lifecycle Hooks](/courses/claude-code/module-06-mcp-and-integrations/02-lifecycle-hooks/)**: Command chalne se pehle aur baad me automatic checks aur linting.
3. **[6.3 Plugins & Ecosystem](/courses/claude-code/module-06-mcp-and-integrations/03-plugins-and-ecosystem/)**: Community plugins aur best practices.

---

## 🔹 **Module 7: Real-World Capstone Projects**
1. **[7.1 Building a Fullstack SaaS App](/courses/claude-code/module-07-production-projects/01-building-fullstack-app/)**: Claude Code terminal se scratch se poora app build karna.
2. **[7.2 Automated Debugging, Testing & PRs](/courses/claude-code/module-07-production-projects/02-automated-debugging-and-testing/)**: Real codebase ke bugs fix karna, tests likhna aur Pull Request generate karna.
