यह कोर्स **7 मॉड्यूल्स** और **18 चैप्टर्स** में बंटा हुआ है। नीचे हर मॉड्यूल के टॉपिक्स की पूरी डिटेल दी गई है:

---

## 🔹 **Module 1: Foundations & Architecture (शुरुआत और बनावट)**
1. **[1.1 Agentic Coding vs Vibe Coding](/courses/claude-code/module-01-foundations/01-agentic-coding-vs-vibe-coding/)**: नॉर्मल चैटबॉट, Copilot ऑटो-कम्प्लीट और Autonomous Agentic Loop में क्या फर्क है?
2. **[1.2 What is Claude Code & Architecture](/courses/claude-code/module-01-foundations/02-what-is-claude-code/)**: टर्मिनल टूल कैसे काम करता है, इसके टूल्स और सेफ्टी रूल्स क्या हैं।
3. **[1.3 Installation & Setup](/courses/claude-code/module-01-foundations/03-installation-and-setup/)**: Node.js, CLI इन्स्टॉल करना (`@anthropic-ai/claude-code`), Anthropic API Key और Free credits का सेटअप।

---

## 🔹 **Module 2: Everyday CLI & Core Workflow (रोज़ के जरूरी कमांड्स)**
1. **[2.1 Slash Commands Mastery](/courses/claude-code/module-02-core-workflow/01-slash-commands-mastery/)**: `/help`, `/init`, `/compact`, `/cost`, `/doctor`, `/review` जैसे जरूरी कमांड्स का पूरा गाइड।
2. **[2.2 Making Code Changes & Diffs](/courses/claude-code/module-02-core-workflow/02-making-code-changes/)**: फाइल्स को एडिट करना, कोड का बदलाव (Diffs) देखना और सेफ तरीके से कमांड्स चलाना।
3. **[2.3 Multimodal Image Context](/courses/claude-code/module-02-core-workflow/03-multimodal-image-context/)**: UI डिज़ाइन, स्क्रीनशॉट और वायरफ्रेम को प्रॉम्प्ट में जोड़कर कोड बनवाना।

---

## 🔹 **Module 3: Context Window & Memory Management (मेमोरी और टोकन की बचत)**
1. **[3.1 Context Window Management](/courses/claude-code/module-03-context-and-memory/01-context-window-management/)**: टोकन लिमिट्स को समझना, पैसे बचाना और `/compact` का सही इस्तेमाल।
2. **[3.2 CLAUDE.md — The Project Brain](/courses/claude-code/module-03-context-and-memory/02-claude-md-the-master-file/)**: प्रोजेक्ट के रूल्स, कोडिंग के तौर-तरीके और जरूरी हिदायतें सेव करना।

---

## 🔹 **Module 4: Development Workflows & Planning (प्लानिंग और वर्कफ़्लो)**
1. **[4.1 Spec-Driven Development (SDD)](/courses/claude-code/module-04-development-workflows/01-spec-driven-development/)**: पहले रिक्वायरमेंट्स और स्पेक्स लिखकर बिना गलती के सटीक कोड बनवाना।
2. **[4.2 Plan Mode & Ultraplan](/courses/claude-code/module-04-development-workflows/02-plan-mode-and-ultraplan/)**: कोड लिखने से पहले स्टेप-बाय-स्टेप प्लानिंग और फाइल्स की आपस की डिपेंडेंसी समझना।
3. **[4.3 Custom Slash Commands](/courses/claude-code/module-04-development-workflows/03-custom-slash-commands/)**: `.claude/commands/` में अपने प्रोजेक्ट के लिए मनपसंद शॉर्टकट कमांड्स बनाना।

---

## 🔹 **Module 5: Skills & SubAgents Architecture (स्किल्स और सब-एजेंट्स)**
1. **[5.1 Claude Code Skills](/courses/claude-code/module-05-skills-and-subagents/01-claude-code-skills/)**: `SKILL.md` बनाकर बार-बार होने वाले कामों और एक्सपर्ट नॉलेज को पैकेज करना।
2. **[5.2 Built-in SubAgents](/courses/claude-code/module-05-skills-and-subagents/02-built-in-subagents/)**: बैकग्राउंड वर्कर एजेंट्स को काम बांटकर टोकन और मुख्य मेमोरी बचाना।
3. **[5.3 Custom SubAgents](/courses/claude-code/module-05-skills-and-subagents/03-custom-subagents/)**: अलग-अलग कामों के लिए अपने वर्कर एजेंट्स (Testing, QA, Documentation) तैयार करना।

---

## 🔹 **Module 6: Model Context Protocol (MCP) & Plugins (बाहरी टूल्स से जोड़ना)**
1. **[6.1 Claude Code with MCP](/courses/claude-code/module-06-mcp-and-integrations/01-claude-code-with-mcp/)**: डेटाबेस (PostgreSQL), GitHub और ब्राउज़र टूल्स को सीधे Claude Code से कनेक्ट करना।
2. **[6.2 Lifecycle Hooks](/courses/claude-code/module-06-mcp-and-integrations/02-lifecycle-hooks/)**: कमांड चलने से पहले और बाद में ऑटोमैटिक सिक्योरिटी व फॉर्मेटिंग चेक लगाना।
3. **[6.3 Plugins & Ecosystem](/courses/claude-code/module-06-mcp-and-integrations/03-plugins-and-ecosystem/)**: कम्युनिटी प्लगइन्स और सबसे जरूरी शॉर्टकट्स की मास्टर चीटशीट।

---

## 🔹 **Module 7: Real-World Capstone Projects (लाइव प्रैक्टिकल प्रोजेक्ट्स)**
1. **[7.1 Building a Fullstack SaaS App](/courses/claude-code/module-07-production-projects/01-building-fullstack-app/)**: Claude Code टर्मिनल के ज़रिए शुरुआत से लेकर अंत तक पूरा फुलस्टैक ऐप बनाना।
2. **[7.2 Automated Debugging, Testing & PRs](/courses/claude-code/module-07-production-projects/02-automated-debugging-and-testing/)**: पुराने प्रोजेक्ट्स के बग्स फिक्स करना, यूनिट टेस्ट्स लिखवाना और Pull Request तैयार करना।
