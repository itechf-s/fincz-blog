# 🤖 **Module 5: Skills & SubAgents Architecture (स्किल्स और सब-एजेंट्स)**

इस मॉड्यूल में हम सीखेंगे कि AI एजेंट की ताकत को **Skills** और **Subagents** के ज़रिए कैसे बढ़ाया जाए। हम जानेंगे कि भारी रिसर्च और टेस्टिंग का काम बैकग्राउंड सब-एजेंट्स को देकर टोकन और मुख्य मेमोरी कैसे बचाएं।

---

## 📑 **इस मॉड्यूल के चैप्टर्स:**

1. **[5.1 Claude Code Skills](/courses/claude-code/module-05-skills-and-subagents/01-claude-code-skills/)**  
   *`SKILL.md` फाइल्स बनाना और खास कामों के लिए एक्सपर्टीज पैकेज करना।*

2. **[5.2 Built-in SubAgents](/courses/claude-code/module-05-skills-and-subagents/02-built-in-subagents/)**  
   *रिसर्च सब-एजेंट्स और मुख्य चैट में 90% टोकन बचाने की तकनीक।*

3. **[5.3 Custom SubAgents](/courses/claude-code/module-05-skills-and-subagents/03-custom-subagents/)**  
   *खास कामों के लिए अपने वर्कर एजेंट्स (Testing, QA, Documentation) तैयार करना।*
