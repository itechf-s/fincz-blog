# ⚡ **Module 2: Everyday CLI & Core Workflow (रोज़ के जरूरी कमांड्स)**

इस मॉड्यूल में हम **Claude Code** के रोज़मर्रा के वर्कफ़्लो और कमांड्स को गहराई से सीखेंगे। हम जानेंगे कि स्लैश कमांड्स कैसे काम करते हैं, कोड बदलाव (Diffs) कैसे चेक करते हैं, और स्क्रीनशॉट या UI डिज़ाइन को प्रॉम्प्ट में कैसे इस्तेमाल करते हैं।

---

## 📑 **इस मॉड्यूल के चैप्टर्स:**

1. **[2.1 Slash Commands Mastery](/courses/claude-code/module-02-core-workflow/01-slash-commands-mastery/)**  
   *`/help`, `/init`, `/compact`, `/cost`, `/doctor`, `/review` और `/clear` का पूरा प्रैक्टिकल गाइड।*

2. **[2.2 Making Code Changes & Diffs](/courses/claude-code/module-02-core-workflow/02-making-code-changes/)**  
   *फाइल्स को एडिट करना, कोड बदलाव (Diffs) को देखना और सेफ तरीके से कमांड्स चलाना।*

3. **[2.3 Multimodal Image Context](/courses/claude-code/module-02-core-workflow/03-multimodal-image-context/)**  
   *UI डिज़ाइन, स्क्रीनशॉट और वायरफ्रेम को प्रॉम्प्ट में जोड़कर कोड बनवाना।*
