# 🤖 **Claude Code: Complete Master Course (Zero to Pro)**

स्वागत है **Claude Code Master Course** में! यह कोर्स आपको सिखाएगा कि कैसे Anthropic के ऑफिशियल AI एजेंट **Claude Code** का इस्तेमाल करके आप एक साधारण डेवलपर से एक **10x Agentic Engineer** बन सकते हैं।

---

## 🎯 **यह कोर्स क्यों खास है?**

नॉर्मल AI चैटबॉट्स (जैसे ChatGPT या Copilot) सिर्फ कोड के छोटे टुकड़े सजेस्ट करते हैं या चैट में कोड देते हैं जिसे आपको खुद कॉपी-पेस्ट करना पड़ता है। लेकिन **Claude Code** सीधे आपके Terminal में रहकर काम करता है:
1. पूरे प्रोजेक्ट के कोड और फाइल्स को एक साथ समझता है।
2. फाइल्स को खुद एडिट और अपडेट करता है।
3. Terminal commands, tests और build खुद चलाकर चेक करता है।
4. अगर कोई एरर आए तो उसे खुद ठीक करके Git PR तक तैयार कर देता है।

## 📚 **मॉड्यूल्स की सूची (Course Modules)**

- 🔹 **[Module 1: Foundations & Architecture](/courses/claude-code/module-01-foundations/)** — Agentic Coding vs Vibe Coding, Claude Code क्या है, और Step-by-Step Installation।
- 🔹 **[Module 2: Everyday CLI & Navigation](/courses/claude-code/module-02-core-workflow/)** — Slash Commands (`/compact`, `/doctor`, `/cost`), कोड एडिट करना, और इमेज/स्क्रीनशॉट का इस्तेमाल।

- 🔹 **[Module 7: Production Capstone Projects](/courses/claude-code/module-07-production-projects/)** — फुलस्टैक SaaS ऐप बनाना और बग्स फिक्स करके PR बनाना।
