# 🤖 **Claude Code: Complete Master Course (Zero to Pro)**

Welcome to **Claude Code Master Course**! Is course me hum seekhenge ki Anthropic ke official autonomous AI agent **Claude Code** ka use karke ek normal developer se **10x Agentic Engineer** kaise banein.

---

## 🎯 **Ye Course Khaas Kyu Hai?**

Normal AI Chatbots (jaise ChatGPT ya Copilot) sirf code ke tukde suggest karte hain ya chat me code likhte hain jisko manually copy-paste karna padta hai. Lekin **Claude Code** seedhe aapke Terminal me kaam karta hai:
1. Poore Project ke code ko ek saath samajhta hai.
2. Files ko khud edit aur update karta hai.
3. Terminal commands, tests aur build khud run karke check karta hai.
4. Agar koi error aaye toh usko khud theek karke Git PR tak bana deta hai.
