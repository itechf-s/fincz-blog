इस मॉड्यूल में हम Java के दिल यानी **Object-Oriented Programming (OOPs)** के चारों मुख्य स्तंभों को वास्तविक दुनिया के उदाहरणों (Real-world Domain Modeling) के साथ गहराई से समझेंगे।

---

## 🎯 **इस मॉड्यूल के मुख्य उद्देश्य (Goals)**
1. **Procedural vs OOP**: ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग की आवश्यकता और सोच।
2. **Classes, Objects & Constructors**: ब्लूप्रिंट, इंस्टेंस मेमोरी और `this` कीवर्ड।
3. **Encapsulation**: डेटा हाइडिंग और सुरक्षित गेटर्स/सेटर्स।
4. **Inheritance**: `extends`, कोड रीयूज़ेबिलिटी और डायमंड प्रॉब्लम।
5. **Polymorphism**: डायनामिक मेथड डिस्पैच और अपकास्टिंग।
6. **Abstraction**: Abstract Classes बनाम Interfaces और डिफ़ॉल्ट मेथड्स।
