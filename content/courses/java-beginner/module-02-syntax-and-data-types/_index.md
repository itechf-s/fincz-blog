इस मॉड्यूल में हम Java के व्याकरण (Grammar & Syntax) को समझेंगे। हम सीखेंगे कि कंप्यूटर मेमोरी में अलग-अलग तरह के डेटा (संख्या, दशमलव, अक्षर, सही/गलत) को कैसे स्टोर किया जाता है, टाइप कास्टिंग कैसे काम करती है, और यूजर से कीबोर्ड के ज़रिए इनपुट कैसे लिया जाता है।

## 🎯 **इस मॉड्यूल के मुख्य उद्देश्य (Goals)**
1. **Java Program Structure**: क्लास, मेथड, स्टेटमेंट्स, कर्ली ब्रैकेट्स और कॉमेंट्स का सही उपयोग।
2. **8 Primitive Data Types**: बाइट्स, साइज़ और मेमोरी रेंजेस को समझना।
3. **Type Casting & Type Promotion**: ऑटोमैटिक वाइडनिंग vs मैनुअल नैरोइंग कास्टिंग।
4. **User Input (Scanner)**: `java.util.Scanner` का उपयोग करके इंटरैक्टिव कंसोल प्रोग्राम्स बनाना।
