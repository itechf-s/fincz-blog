इस मॉड्यूल में हम Java में कोड को पुनः प्रयोज्य (Reusable) और मॉड्यूलर बनाने के लिए **Methods (Functions)** की अवधारणा को गहराई से समझेंगे।

---

## 🎯 **इस मॉड्यूल के मुख्य उद्देश्य (Goals)**
1. **Method Anatomy**: रिटर्न टाइप्स, पैरामीटर्स और मेथड सिग्नेचर को समझना।
2. **Pass-by-Value in Java**: जावा मेमोरी में प्रिमिटिव और ऑब्जेक्ट रेफ़रेंस कैसे पास होते हैं।
3. **Method Overloading vs Overriding**: कम्पाइल-टाइम और रन-टाइम पॉलीमॉर्फिज़्म की नींव।
4. **Static vs Instance Methods**: `static` कीवर्ड का मेमोरी पर प्रभाव और उपयोग के नियम।
