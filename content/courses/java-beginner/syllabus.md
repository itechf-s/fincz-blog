## 📜 **Java Beginner to Pro: सम्पूर्ण पाठ्यक्रम (Curriculum)**

> 💡 **भाषा:** सरल हिंग्लिश (आसान दैनिक बोलचाल वाली हिंदी + तकनीकी शब्दावली)  
> 🎯 **लक्षित पाठक:** बिगिनर्स, कॉलेज स्टूडेंट्स और बैकएंड सॉफ्टवेयर इंजीनियरिंग के आकांक्षी।

---

### 📘 [Module 1: Introduction, Architecture & Setup](/courses/java-beginner/module-01-introduction-and-setup/)
1. **[1.1 Java का परिचय और आर्किटेक्चर](/courses/java-beginner/module-01-introduction-and-setup/01-introduction-to-java/)** — Java का इतिहास, WORA सिद्धांत, JDK vs JRE vs JVM, और पहला 'Hello World' प्रोग्राम।
2. **[1.2 Java Installation & Environment Setup (Latest LTS)](/courses/java-beginner/module-01-introduction-and-setup/02-java-installation/)** — Windows, Linux, macOS पर Latest Java LTS (Java 25 / 21) इंस्टॉलेशन, `JAVA_HOME` और IDE कॉन्फ़िगरेशन।
3. **[1.3 Java Keywords & Compilation Lifecycle](/courses/java-beginner/module-01-introduction-and-setup/03-keywords-and-architecture/)** — Java के 50+ कीवर्ड्स चार्ट और बाइटकोड एक्ज़ीक्यूशन फ़्लो।

---

### 🔤 [Module 2: Java Syntax, Variables & Data Types](/courses/java-beginner/module-02-syntax-and-data-types/)
1. **[2.1 Java Syntax और Program Structure](/courses/java-beginner/module-02-syntax-and-data-types/01-java-syntax-and-structure/)** — क्लास संरचना, `main()` मेथड, स्टेटमेंट्स, कर्ली ब्रैकेट्स और कॉमेंट्स।
2. **[2.2 Variables & 8 Primitive Data Types](/courses/java-beginner/module-02-syntax-and-data-types/02-variables-and-data-types/)** — प्रिमिटिव डेटा टाइप्स (byte, short, int, long, float, double, char, boolean), मेमोरी साइज़ और रेंज।
3. **[2.3 Type Casting & Type Promotion](/courses/java-beginner/module-02-syntax-and-data-types/03-type-casting-and-promotion/)** — ऑटोमैटिक वाइडनिंग प्रमोशन vs नैरोइंग एक्सप्लिसिट कास्टिंग और डेटा लॉस।
4. **[2.4 User Input using Scanner Class](/courses/java-beginner/module-02-syntax-and-data-types/04-user-input-scanner/)** — `java.util.Scanner` का उपयोग, इनपुट मेथड्स, और न्यूलाइन बफ़र बग का समाधान।

---

### 🔁 [Module 3: Control Flow Statements & Decision Logic](/courses/java-beginner/module-03-control-flow/)
1. **[3.1 Conditional Statements (if-else & Switch)](/courses/java-beginner/module-03-control-flow/01-conditional-statements/)** — `if`, `if-else`, `else-if` लैडर, नेस्टेड कंडीशन्स, और मॉडर्न स्विच एक्सप्रेशन्स।
2. **[3.2 Loops & Iterations (for, while, do-while)](/courses/java-beginner/module-03-control-flow/02-loops-and-iterations/)** — `for`, `while`, `do-while`, एन्हांस्ड `for-each` लूप, और इनफिनिट लूप्स से बचाव।
3. **[3.3 Jump Statements & Control Flowchart](/courses/java-beginner/module-03-control-flow/03-jump-statements-and-flowcharts/)** — `break`, `continue`, लेबल्ड लूप्स, और विज़ुअल डिसीजन फ़्लोचार्ट।

---

### 🔧 [Module 4: Functions & Methods](/courses/java-beginner/module-04-functions-and-methods/)
1. **[4.1 Functions & Methods in Java](/courses/java-beginner/module-04-functions-and-methods/01-functions-and-methods/)** — मेथड एनाटॉमी, रिटर्न टाइप्स, पैरामीटर्स, और Java में Pass-by-Value का सिद्धांत।
2. **[4.2 Method Overloading](/courses/java-beginner/module-04-functions-and-methods/02-method-overloading/)** — कम्पाइल-टाइम पॉलीमॉर्फिज़्म, पैरामीटर रूल्स, और कैलकुलेटर उदाहरण।
3. **[4.3 Method Overriding](/courses/java-beginner/module-04-functions-and-methods/03-method-overriding/)** — रन-टाइम पॉलीमॉर्फिज़्म, `@Override` एनोटेशन, और `super` कीवर्ड।
4. **[4.4 Static vs Instance Methods](/courses/java-beginner/module-04-functions-and-methods/04-static-vs-instance-methods/)** — स्टैटिक मेमोरी एलोकेशन, `main()` मेथड का स्टैटिक होना, और उपयोग के नियम।

---

### 🧱 [Module 5: Arrays & Strings in Java](/courses/java-beginner/module-05-arrays-and-strings/)
1. **[5.1 Arrays in Java (1D & 2D)](/courses/java-beginner/module-05-arrays-and-strings/01-arrays-in-java/)** — 1D और 2D ऐरे, हीप मेमोरी स्ट्रक्चर, इंडेक्सिंग और ऐरे मैनिपुलेशन।
2. **[5.2 Strings & String Constant Pool (SCP)](/courses/java-beginner/module-05-arrays-and-strings/02-strings-and-string-pool/)** — स्ट्रिंग की इम्यूटेबिलिटी (Immutability), SCP vs Heap, `==` vs `.equals()`, और `StringBuilder`।
3. **[5.3 String Methods Cheat Sheet](/courses/java-beginner/module-05-arrays-and-strings/03-string-functions-reference/)** — महत्वपूर्ण 15+ स्ट्रिंग मेथड्स और उनके लाइव कोड उदाहरण।
4. **[5.4 Practice Assignment & Solutions](/courses/java-beginner/module-05-arrays-and-strings/04-practice-assignment/)** — 10 हैंड्स-ऑन कोडिंग प्रॉब्लम्स और उनके विस्तृत समाधान।

---

### 🏛️ [Module 6: Object-Oriented Programming (OOPs)](/courses/java-beginner/module-06-oops-fundamentals/)
1. **[6.1 OOPs Fundamentals & Core Pillars](/courses/java-beginner/module-06-oops-fundamentals/01-oops-introduction/)** — प्रोसीजरल vs OOPs, और OOPs के 4 मुख्य स्तंभ।
2. **[6.2 Class, Object & Constructors](/courses/java-beginner/module-06-oops-fundamentals/02-class-and-object/)** — ब्लूप्रिंट vs इंस्टेंस, कंस्ट्रक्टर्स, `this` कीवर्ड और ऑब्जेक्ट लाइफसाइकिल।
3. **[6.3 Encapsulation & Data Hiding](/courses/java-beginner/module-06-oops-fundamentals/03-encapsulation/)** — प्राइवेट फील्ड्स, गेटर्स/सेटर्स में वैलिडेशन, और JavaBean स्टैंडर्ड्स।
4. **[6.4 Inheritance & Code Reusability](/courses/java-beginner/module-06-oops-fundamentals/04-inheritance/)** — IS-A रिलेशनशिप, `extends` कीवर्ड, इनहेरिटेंस के प्रकार, और डायमंड प्रॉब्लम।
5. **[6.5 Polymorphism & Dynamic Dispatch](/courses/java-beginner/module-06-oops-fundamentals/05-polymorphism/)** — कम्पाइल-टाइम vs रन-टाइम पॉलीमॉर्फिज़्म, और अपकास्टिंग/डाउनकास्टिंग।
6. **[6.6 Abstraction & Interfaces](/courses/java-beginner/module-06-oops-fundamentals/06-abstraction/)** — Abstract Classes vs Interfaces, `implements` कीवर्ड, और डिफ़ॉल्ट मेथड्स।

### 🧬 [Module 7: Packages & Access Modifiers](/courses/java-beginner/module-07-packages-and-access-modifiers/)
1. **[7.1 Packages & Access Modifier Matrix](/courses/java-beginner/module-07-packages-and-access-modifiers/01-access-modifiers-and-packages/)** — पैकेज नेमिंग, `import`, और 4 एक्सेस मॉडिफायर्स (`public`, `protected`, `default`, `private`) की मैट्रिक्स।
2. **[7.2 Real-World Banking System Architecture](/courses/java-beginner/module-07-packages-and-access-modifiers/02-real-world-bank-domain-example/)** — बैंकिंग डोमेन के साथ पैकेज बाउंड्रीज़ और एक्सेस प्रोटेक्शन का लाइव प्रोजेक्ट।

### ⚠️ [Module 8: Exception Handling in Java](/courses/java-beginner/module-08-exception-handling/)
1. **[8.1 Exception Handling Basics](/courses/java-beginner/module-08-exception-handling/01-exception-handling-basics/)** — Error vs Exception, `try`, `catch`, `finally` ब्लॉक और एक्सेप्शन फ़्लो।
2. **[8.2 Checked vs Unchecked Exceptions](/courses/java-beginner/module-08-exception-handling/02-checked-vs-unchecked-exceptions/)** — कम्पाइल-टाइम vs रन-टाइम एक्सेप्शन और सामान्य रनटाइम एरर्स।
3. **[8.3 Try-with-Resources (AutoCloseable)](/courses/java-beginner/module-08-exception-handling/03-try-with-resources/)** — ऑटोमैटिक रिसोर्स मैनेजमेंट और मेमोरी लीक की रोकथाम।
4. **[8.4 Exception Hierarchy & Catch Rules](/courses/java-beginner/module-08-exception-handling/04-exception-hierarchy/)** — `Throwable` क्लास पदानुक्रम, मल्टी-कैच और कैच ब्लॉक्स का सही क्रम।
5. **[8.5 Custom Exceptions (throw vs throws)](/courses/java-beginner/module-08-exception-handling/05-custom-exceptions/)** — अपने कस्टम एक्सेप्शन बनाना, `throw` और `throws` का सटीक उपयोग।

### 📁 [Module 9: File Handling & I/O Streams](/courses/java-beginner/module-09-file-handling-and-io/)
1. **[9.1 File Handling Basics](/courses/java-beginner/module-09-file-handling-and-io/01-file-handling-basics/)** — `java.io.File`, फ़ाइल बनाना, पढ़ना, मेटाडेटा चेक करना और डिलीट करना।
2. **[9.2 Directory Operations](/courses/java-beginner/module-09-file-handling-and-io/02-directory-operations/)** — फ़ोल्डर क्रिएशन (`mkdir`, `mkdirs`), फ़ाइल लिस्टिंग और रिकर्सिव सर्च।
3. **[9.3 Byte Streams vs Character Streams](/courses/java-beginner/module-09-file-handling-and-io/03-io-streams/)** — `FileInputStream`/`FileOutputStream` vs `BufferedReader`/`BufferedWriter`।

### 🗃️ [Module 10: Java Collections Framework (JCF)](/courses/java-beginner/module-10-collections-framework/)
1. **[10.1 Collections Framework Overview](/courses/java-beginner/module-10-collections-framework/01-collections-framework-overview/)** — ऐरे की सीमाएँ, Collection Hierarchy, और कोर इंटरफेसेस।
2. **[10.2 List Interface (ArrayList vs LinkedList)](/courses/java-beginner/module-10-collections-framework/02-list-interface/)** — `ArrayList` का इंटरनल रीसाइज़िंग और `LinkedList` के साथ परफ़ॉर्मेंस तुलना।
3. **[10.3 Set Interface (HashSet vs TreeSet)](/courses/java-beginner/module-10-collections-framework/03-set-interface/)** — डुप्लीकेट्स हटाना, हैशिंग, और सॉर्टेड डेटा स्टोरेज।
4. **[10.4 Map Interface (HashMap Internal Working)](/courses/java-beginner/module-10-collections-framework/04-map-interface/)** — Key-Value पेयर्स, `hashCode()` और `equals()` का इंटरनल बकेट आर्किटेक्चर।
5. **[10.5 Iterators & Fail-Fast vs Fail-Safe](/courses/java-beginner/module-10-collections-framework/05-iterators-fail-fast-vs-fail-safe/)** — `Iterator`, `ListIterator`, और `ConcurrentModificationException` से सुरक्षा।

### 🛠️ [Module 11: Generics & Wrapper Classes](/courses/java-beginner/module-11-generics-and-wrappers/)
1. **[11.1 Generics & Autoboxing](/courses/java-beginner/module-11-generics-and-wrappers/01-generics-autoboxing-wrapper-classes/)** — Type Safety, जेनेरिक मेथड्स/क्लासेस, और प्रिमिटिव रैपर क्लासेस।
2. **[11.2 Generics Cheat Sheet & Wildcards](/courses/java-beginner/module-11-generics-and-wrappers/02-generics-cheat-sheet/)** — वाइल्डकार्ड्स (`? extends T`, `? super T`), PECS सिद्धांत और Type Erasure।

### ⚡ [Module 12: Multithreading & Concurrency](/courses/java-beginner/module-12-multithreading-and-concurrency/)
1. **[12.1 Multithreading Fundamentals](/courses/java-beginner/module-12-multithreading-and-concurrency/01-multithreading-concurrency-basics/)** — प्रोसेस vs थ्रेड, थ्रेड बनाने के तरीके (`Thread` vs `Runnable`), और थ्रेड स्टेट्स।
2. **[12.2 Thread Methods & Synchronization](/courses/java-beginner/module-12-multithreading-and-concurrency/02-thread-methods-and-synchronization/)** — `sleep()`, `join()`, रेस कंडीशन्स, और `synchronized` ब्लॉक्स/लॉक्स।
3. **[12.3 Thread Pools & ExecutorService](/courses/java-beginner/module-12-multithreading-and-concurrency/03-thread-pool-and-executors/)** — थ्रेड पूल्स का महत्व, `FixedThreadPool`, `Callable` और `Future`।
4. **[12.4 Thread Scheduling & Deadlock Prevention](/courses/java-beginner/module-12-multithreading-and-concurrency/04-thread-scheduling-and-deadlock/)** — थ्रेड प्रायोरिटी, डेडलॉक की 4 शर्तें और डेडलॉक से बचाव।

### 💾 [Module 13: JDBC & Database Operations](/courses/java-beginner/module-13-jdbc-database/)
1. **[13.1 JDBC Fundamentals & CRUD](/courses/java-beginner/module-13-jdbc-database/01-jdbc-fundamentals/)** — JDBC आर्किटेक्चर, 5 कोर स्टेप्स, और `PreparedStatement` से SQL Injection से सुरक्षा।
2. **[13.2 Connection Pooling (HikariCP)](/courses/java-beginner/module-13-jdbc-database/02-connection-pooling/)** — कनेक्शन पूलिंग क्यों ज़रूरी है, HikariCP का सेटअप और बेस्ट प्रैक्टिसेज।
3. **[13.3 Transaction Management & ACID](/courses/java-beginner/module-13-jdbc-database/03-transaction-management/)** — ACID सिद्धांत, `commit()`, `rollback()`, Savepoints और वित्तीय डेटा सुरक्षा।
