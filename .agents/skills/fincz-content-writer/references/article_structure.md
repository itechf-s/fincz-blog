# Reference: Fincz Article Structure & Patterns

## Diagram Patterns (ASCII)

Use clean text-based boxes for visual workflows:

```text
┌───────────────────────────────────────────────────────────┐
│                     System Overview                       │
├─────────────────┬───────────────────┬─────────────────────┤
│ 1. Input Layer  │ 2. Processing     │ 3. Storage / Output │
└─────────────────┴───────────────────┴─────────────────────┘
```

## Comparison Table Format

| Feature / Tool | Asli Kaam (Role) | Advantages (Fayde) | Disadvantages (Nuksan) |
| :--- | :--- | :--- | :--- |
| **Tool A** | Primary orchestration | High performance | Complex config |
| **Tool B** | Specific task resolver | Simple setup | Limited integrations |

## Conclusion / Nateeja Format

End every guide with:
1. **Nateeja (Conclusion)**: High-level takeaway for working professionals.
2. **Quick Revision Summary**: 5-7 concise bullet points.
